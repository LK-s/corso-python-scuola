# Introduzione a Python per la scuola

Materiale del corso di introduzione a **Python 3.15** per insegnanti delle scuole secondarie di secondo grado. Nessuna esperienza di programmazione richiesta.

Il corso ha quattro lezioni da due ore. Ambiente di lavoro: **Windows + Thonny**.

## Come scaricare il materiale (senza account GitHub)

Repository: <https://github.com/LK-s/corso-python-scuola>

1. Su questa pagina premere il pulsante verde **Code**.
2. Scegliere **Download ZIP**.
3. Estrarre lo ZIP in una cartella, per esempio `C:\Corso_Python`.
   Il file scaricato si chiama `corso-python-scuola-main.zip` e, una volta estratto, contiene la cartella `corso-python-scuola-main` con tutto il materiale.

## Come leggere le dispense (file `.md`)

Le dispense e le guide sono file Markdown (`.md`). Aperti con un doppio clic in Windows compaiono
come testo grezzo, con simboli come `#` e `|---|` ben visibili, e le tabelle risultano poco leggibili.

- **Online, su GitHub** (consigliato): aprire la cartella nel repository e cliccare su `README.md`;
  GitHub lo mostra già formattato. Serve la connessione a Internet.
- **Offline**: il Blocco note apre i file `.md` come testo semplice: si legge, ma senza formattazione.
- **Facoltativo, Visual Studio Code** (gratuito): apre i file `.md` con l'anteprima formattata
  (premere `Ctrl+Maiusc+V`). Con l'estensione *Python* si può usare anche per scrivere ed eseguire
  il codice, al posto di Thonny: nel corso usiamo Thonny, ma chi preferisce VS Code può usarlo.

Thonny serve per i file `.py`: non mostra i `.md` formattati.

## Come eseguire un file

1. Aprire Thonny.
2. **File → Apri…** e scegliere il file `.py`.
3. Premere il pulsante verde ▶ (oppure **F5**).

Gli esempi stampano risultati e in alcuni casi chiedono dei valori: i valori si scrivono nella Shell,
in basso, seguiti da Invio.
