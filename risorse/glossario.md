# Glossario

I termini che si incontrano nelle prime lezioni, in ordine alfabetico. Tra parentesi la forma inglese, utile per cercare in rete.

| Termine | Significato |
| --- | --- |
| **Argomento** (*argument*) | Il valore che si passa a una funzione quando la si usa: in `round(3.14159, 2)` gli argomenti sono `3.14159` e `2` |
| **Assegnazione** (*assignment*) | L'istruzione `nome = valore`, che associa un nome a un valore |
| **Booleano** (*boolean*) | Tipo con due soli valori, `True` e `False` |
| **Ciclo** (*loop*) | Parte di programma che si ripete: `for` quando si sa quante volte, `while` finché una condizione è vera |
| **Ciclo infinito** | Ciclo che non finisce mai perché la condizione resta sempre vera; si ferma con il pulsante Stop |
| **Commento** (*comment*) | Testo che segue `#` e che Python ignora; serve per spiegare il codice |
| **Condizione** (*condition*) | Espressione che risulta vera o falsa, come `ph < 7` |
| **Debug** | Ricerca e correzione degli errori in un programma; in Thonny si può eseguire il codice una riga alla volta |
| **Editor** | Programma in cui si scrive il codice (per noi Thonny) |
| **Errore** (*error, exception*) | Messaggio che Python mostra quando non riesce a eseguire il programma; l'ultima riga dice il tipo e il motivo |
| **Espressione** (*expression*) | Qualcosa che ha un valore, come `2 + 3` o `math.sqrt(16)` |
| **f-string** | Testo tra virgolette preceduto da `f`, con valori tra graffe: `f"Area: {a:.2f}"` |
| **Float** | Tipo dei numeri decimali (con la virgola mobile), come `3.14` |
| **Frazione** (*Fraction*) | Numero razionale esatto del modulo `fractions`: `Fraction(1, 3)`; con le frazioni i calcoli non hanno errori di arrotondamento |
| **Funzione** (*function*) | Blocco di istruzioni con un nome, che si definisce con `def` e si può usare quante volte si vuole; `print` e `len` sono funzioni già pronte |
| **Indentazione, rientro** (*indentation*) | Gli spazi all'inizio della riga, che in Python indicano a quale blocco appartiene |
| **Indice** (*index*) | La posizione di un elemento in una lista o in un testo; si parte da 0 |
| **Input** | I dati che l'utente scrive; in Python si leggono con `input()` e arrivano sempre come testo |
| **Installare** | Aggiungere un programma o una libreria al computer; per le librerie Python si usa `pip` |
| **Intero** (*int*) | Tipo dei numeri senza parte decimale, come `42` |
| **Interprete** (*interpreter*) | Il programma che legge il codice Python e lo esegue; è ciò che installiamo come «Python» |
| **Libreria** (*library*) | Raccolta di funzioni già pronte per un compito, come NumPy per i calcoli o matplotlib per i grafici |
| **Libreria standard** (*standard library*) | Le librerie incluse in Python, come `math` e `random`: non vanno installate |
| **Lista** (*list*) | Sequenza ordinata di valori tra parentesi quadre, come `[12.1, 11.8, 12.4]` |
| **Metodo** (*method*) | Funzione che appartiene a un tipo di dato e si usa con il punto: `"ciao".upper()`, `misure.append(3)` |
| **Modulo** (*module*) | File di Python con funzioni pronte da importare con `import`: `import math` |
| **Operatore** (*operator*) | Simbolo che esegue un'operazione, come `+`, `//`, `%`, `==`, `and` |
| **Output** | Ciò che il programma mostra, di solito con `print()` |
| **Parametro** (*parameter*) | Il nome con cui una funzione chiama un valore che riceve, nella sua definizione: in `def area(raggio):` il parametro è `raggio` |
| **pip** | Programma che scarica e installa le librerie da PyPI: `py -m pip install nome` |
| **PyPI** | L'archivio pubblico dei pacchetti Python, da cui pip scarica le librerie |
| **Programma, script** | Un file `.py` con una serie di istruzioni che Python esegue dall'alto verso il basso |
| **Shell** | Il pannello di Thonny in cui compaiono i risultati e in cui si possono provare istruzioni una alla volta |
| **Sintassi** (*syntax*) | Le regole di scrittura del linguaggio; un errore di sintassi è un `SyntaxError` |
| **Stringa** (*string, str*) | Tipo del testo, scritto tra virgolette: `"ciao"` |
| **Tipo** (*type*) | La natura di un valore: intero, decimale, testo, vero/falso, lista… Si vede con `type(x)` |
| **Valore di ritorno** (*return value*) | Ciò che una funzione restituisce con `return` e che si può assegnare a una variabile |
| **Variabile** (*variable*) | Un nome associato a un valore, che può cambiare durante il programma |
| **Variabile locale** | Variabile creata dentro una funzione: esiste solo lì |
| **Versione** (*version*) | Il numero della release di Python (3.15) o di una libreria; librerie diverse possono richiedere versioni diverse di Python |
